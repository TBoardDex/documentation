# Hardware Open Source License

## What is open

The TBoard hardware design files are published for every board revision:

- Schematic
- PCB layout / fabrication files
- Mechanical drawings and board dimensions
- Pinout and connector definitions
- Bill of materials where available

Design files are released per hardware revision in the [forum](https://forum.tboard.org)
release posts, alongside the matching SDK/BSP version.
