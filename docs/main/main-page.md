# TBoard Documentation

Official documentation for TBoard open-source hardware and software, built on
the Rockchip RK3588 / RK3588S platform.

## Products

- [TBoard R5A](/tboard-r5a) — RK3588S development board

## Where to start

- **Getting Started** — downloads, flashing, first boot and system setup.
- **Interface Usage** — 40-pin header, GPIO, I2C, UART, SPI, camera, display and more.
- **Advanced Manual** — SDK build, device tree overlays, boot flow and NPU workloads.
- **Build & Deploy** — the firmware build chain that produces `update.img`.
- **Open Source** — software and hardware licensing terms.

## Community

Questions, design files and release announcements are published on the
[forum](https://forum.tboard.org). Source repositories live under
[TBoardDex on GitHub](https://github.com/TBoardDex).
