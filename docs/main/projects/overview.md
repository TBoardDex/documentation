This section collects complete case studies built on TBoard boards — not a
single interface or a quick-start path, but an end-to-end solution you can
reproduce: hardware list, wiring, image and driver setup, application code and
the verified result. Typical examples: edge-AI vision gateways, media players,
industrial controllers, robot platforms and classroom kits.

## How a project is documented

One subdirectory per project under `projects/<project-name>/` (lower case):

| Page | Contents |
|---|---|
| `overview.md` | Goal, bill of materials, system block diagram |
| `build.md` | Step-by-step wiring, image flashing and configuration |
| `run.md` | Deploy the application, expected output, troubleshooting |

Start from the board's [Quick Start](/quick-start) before following a project,
and keep the project pages linked to the interfaces they use.
