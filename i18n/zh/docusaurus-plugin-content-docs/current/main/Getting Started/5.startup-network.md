# 网络配置

> **草稿** —— 本页是干净的结构占位页，内容就绪后请替换为经过验证的 TBoard 操作流程。

## 本页应写什么

有线与无线网络配置、静态 IP 与主机名设置。

## 写作检查清单

- 只使用 TBoard 自有域名与下载地址。
- MDX 中不要直接写尖括号；`<SoC>` 这类占位符要用反引号包裹。
- 图片放 `static/img/`，引用写法为 `/img/...`。
- 板级参数统一放在 [TBoard R5A](/tboard-r5a) 页面。
