# I2C

瑞芯微方案的 TBoard 板卡在 40-pin 排针上引出 I2C 总线，用于连接传感器、RTC 等
低速外设。所有总线均为 **3.3 V** 电平、板载上拉。引出的总线数量、总线编号、
引脚位置与默认状态由板卡决定——请查看 Boards 下对应板卡的引脚定义页与接口
使用页。

## 总线与板载器件

板卡通常把一部分 SoC I2C 控制器留给板载外设（音频 codec、RTC、摄像头 sensor、
PMIC 监控），另一部分引到排针给用户设备使用。这些总线都能看到：

```bash
ls /dev/i2c-*
```

已经挂着板载芯片的总线不要重新配置——该总线上的 codec、RTC 或摄像头会因此失效。
各板卡接口使用页会标出哪些总线可供外部设备使用。

## 扫描总线

```bash
i2cdetect -y 1        # 扫描总线 1
i2cdetect -y 6        # 扫描总线 6
i2cdetect -y -r 1     # 读模式扫描，适合不接受快速写探测的器件
```

地址显示 `UU` 表示该地址已被驱动占用；显示数字表示有设备在该地址响应。板载
器件（RTC、codec）通常在其总线上显示 `UU`——属正常现象，不是地址冲突。

## 读写寄存器

```bash
i2cget -y 1 0x48 0x00            # 读一个字节
i2cset -y 1 0x48 0x01 0x60       # 写一个字节
i2cget -y 1 0x48 0x00 w          # 读 16 位
i2ctransfer -y 1 w1@0x48 0x00 r2 # 先写寄存器地址，再读 2 字节
```

寄存器型器件建议用 `i2ctransfer`：裸 `i2cget` 走的是组合的写-读时序，部分芯片
不接受。报 `Remote I/O error`（NACK）说明地址错、器件没供电，或缺少上拉。

## 速率与布线

- 默认时钟 **100 kHz**，多数传感器支持 400 kHz。线较长或一块转接板上挂多个
  器件时，建议保持 100 kHz。
- 总线总电容控制在约 400 pF 以内。超过时降低时钟，或增加总线缓冲器。
- 地址冲突无法用软件解决：两个同地址器件需要 mux（如 TCA9548A）或另一条总线。
- 5 V 的 I2C 器件必须加电平转换，SoC 引脚不耐 5 V。
