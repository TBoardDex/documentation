## 本页应写什么

工厂用 update.img、各板卡的 Linux 与 Android 镜像、发布说明、校验和，以及各镜像推荐的烧录工具。


## 写作检查项

- 只使用 TBoard 自有域名与下载地址。
- 板卡专属参数统一写在 [TBoard R5A](/zh/tboard-r5a) 页面。
- 图片放在 `static/img/`，用 `/img/...` 引用。
- MDX 会解析尖括号，`<SoC>` 这类占位请放进反引号。
