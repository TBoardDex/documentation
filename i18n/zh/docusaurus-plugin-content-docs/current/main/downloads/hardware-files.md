# 硬件资料

![硬件文档包占位图 960 x 540 px](/img/placeholder-960x540.png)

> 图片占位：**960 × 540 px**（建议用途：文档 / 图纸包总览）。后期请替换为
> 相同尺寸的真实图片。

R5A 的设计资料发布在 [TBoard 网盘](https://drive.google.com/drive/folders/1x2KOX1F4-DVyyV_9qfdH28PWIORcWH56)
**硬件资料** 目录下的 R5A 产品文件夹中，是底板设计、外壳建模和维修的参考依据。

## 资料包内容

| 文件 | 格式 | 用途 |
|---|---|---|
| 原理图 | PDF | 每个连接器与电源轨的网络级参考 |
| PCB 版图 | PDF / 源文件 | 层叠结构、阻抗、禁布区 |
| 2D 图纸 | DXF | 外壳开孔与安装孔定位 |
| 3D 模型 | STEP | 结构集成 |
| BOM | XLSX / PDF | 物料清单与各版本替代料 |
| 连接器手册 | PDF | FPC、风扇、RTC 与 40-pin 排针的对配件型号 |
| 质检报告 | PDF | 该生产批次的出厂测试结果 |

引脚级信息见 [R5A 40-PIN 引脚定义](/r5a-pinout)，本页只介绍可下载的文档。

## 硬件版本

| 版本 | 改动 |
|---|---|
| V1.0 | 首个量产版本 |
| V1.1 | U27 / U7 / U6301 电源引脚调整；USB U15 由 TypeC1 改为 TypeC0，CN31 由 USB 3.0 改为 USB 2.0；40-pin 增加 UART 保护，J2 / CN2 / CN32 改为 0.8 mm 间距连接器；CSI1 的 I2C 由 I2C3 改为 I2C4 并去除 R6352；Wi-Fi 模组由 AP6275S 改为 AP6275P |

对照原理图测量前，先确认丝印上的版本号和 Wi-Fi 模组的丝印型号。旧版本的
文档仍保留在同一目录，文件名中带有版本标识。

## 使用这些资料

- **结构设计**：用 STEP 模型做外壳，天线区域必须留空——板载 Wi-Fi 天线不能
  被金属板覆盖。
- **散热**：SoC 与 LPDDR4 堆叠是主要热源，2D 图纸中给出了散热器接触面尺寸。
- **供电**：Type-C 输入支持 **5 V – 23 V**。设计底板时保留输入保护，不要把
  5 V 反灌进 40-pin 排针。
- **对配件**：CSI / DSI 为 0.5 mm 间距 FPC，风扇与 RTC 电池为 0.8 mm 间距。
  间距买错是摄像头、屏幕“没反应”的最常见原因。

## 检修与验证

1. 把丝印版本与原理图版本对齐。
2. 更换元件前先按原理图测电源轨：3.3 V、5 V 与 DRAM 供电。
3. 某一路缺失时，先怀疑 PMIC（RK806），原理图上标有测试点。
4. 维修完成后，按[首次启动](/first-boot)做基础检查，并按 [GPIO](/gpio)、
   [I2C](/i2c)页面的方法扫描接口。
