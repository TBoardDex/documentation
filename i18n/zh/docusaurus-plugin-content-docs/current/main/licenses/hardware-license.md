# 硬件开源协议

![TBoard placeholder image 640 x 360 px](/img/placeholder-640x360.png)

> 图片占位：**640 × 360 px**（建议用途：许可说明配图）。后续请用同尺寸的真实图片替换。


## 开放内容

TBoard 按硬件版本发布以下设计文件：

- 原理图
- PCB 布局 / 生产文件
- 机械图纸与板框尺寸
- 引脚与连接器定义
- 可用的物料清单

设计文件随硬件版本在[论坛](https://forum.tboard.org)发布帖中提供，并标注对应的 SDK / BSP 版本。

## 许可证

硬件设计文件采用 **知识共享 署名-相同方式共享 4.0 国际
（CC BY-SA 4.0）** 许可。

允许：

- **共享** —— 以任何媒介或格式复制、再分发设计文件。
- **演绎** —— 修改、转换并基于设计文件再创作，包括商业用途。

须遵守：

- **署名** —— 标注 TBoard 出处、提供许可证链接，并说明是否作出修改。
- **相同方式共享** —— 若演绎或转换设计文件，须以同样的 CC BY-SA 4.0 许可分发你的贡献。
- **不得附加限制** —— 不得施加法律条款或技术措施，限制他人行使许可证允许的行为。

## 商标

**TBoard** 名称与标识为福州天枢科技的商标，**不在** CC BY-SA 4.0 授权范围内。
未经书面许可，不得使用该商标命名衍生硬件；"兼容 TBoard R5A" 之类的描述性引用允许使用。
