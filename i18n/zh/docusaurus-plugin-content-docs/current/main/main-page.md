# TBoard 文档

TBoard 开源硬件与软件的官方文档，基于 Rockchip RK3588 / RK3588S 平台。

## 产品

- [TBoard R5A](/tboard-r5a) —— RK3588S 开发板

## 从哪开始

- **快速开始** —— 资料下载、镜像烧录、首次上电与系统配置。
- **接口使用** —— 40pin 排针、GPIO、I2C、UART、SPI、摄像头、显示屏等。
- **进阶手册** —— SDK 构建、设备树 overlay、启动流程与 NPU 应用。
- **构建与部署** —— 产出 `update.img` 的固件构建链。
- **开源协议** —— 软件与硬件许可条款。
