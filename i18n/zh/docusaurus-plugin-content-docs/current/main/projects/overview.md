# 项目案例

![项目案例分区总览占位图 1200 x 675 px](/img/placeholder-1200x675.png)

> 图片占位：**1200 × 675 px**（建议用途：成品案例照片拼图）。后期请替换为
> 相同尺寸的真实图片。

本分区收集基于 TBoard 板卡搭建的完整案例——不是某个接口的用法，也不是快速
上手流程，而是可以完整复现的端到端方案：硬件清单、接线、镜像与驱动配置、
应用代码以及验证结果。典型场景：边缘 AI 视觉网关、媒体播放、工业控制、
机器人平台与教学套件。

## 案例的组织方式

每个案例一个子目录：`projects/<project-name>/`（小写）：

| 页面 | 内容 |
|---|---|
| `overview.md` | 目标、物料清单、系统框图 |
| `build.md` | 接线、烧录与配置的分步流程 |
| `run.md` | 应用部署、预期输出、故障排查 |

跟做案例前，请先完成对应板卡的[快速上手](/quick-start)；案例页面应链接到
它用到的接口文档。
