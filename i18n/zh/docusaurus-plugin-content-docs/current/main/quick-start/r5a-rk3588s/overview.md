## 命名规范

本分区按板卡分组，分组名中带主控型号：`R5A（RK3588S）`。新增板卡时，在
`quick-start/` 下建同级目录 `<型号>-<主控>`（小写），复制本组页面，并把
`_category_.json` 的 `label` 写成如 `R5B（RK3576）` 的形式，便于后续多平台快速定位。
